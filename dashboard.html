Enforcement Policy Overview

          

            ConsentGuard acts as an inline Policy Enforcement Point (PEP) guarding healthcare and user data downstream. Rather than relying on frontend flags, every downstream request is authenticated via SQLite records linked to the cryptographic digest of the privacy policy.
          

          

            Security Boundary Guarantees:
            
    
              
  • Strict itemized consent: Opting into Analytics never authorizes Marketing or Service Improvement.
    • 
              
  • Zero-latency revocation: Withdrawing consent blocks subsequent requests immediately (HTTP 403).
    • 
              
  • Notice version invalidation: Upgrading privacy terms automatically invalidates prior consents until re-consent is recorded.
    •
