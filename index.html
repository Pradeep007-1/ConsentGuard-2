Technical Specification: Cryptographic Hash Chaining Mechanism
Every audit event in SQLite is chained to its immediate predecessor using SHA-256 digest calculation: row_hash = sha256(prev_hash + user_id + action + purpose + http_status + reason_code + created_at). Any retro-active tampering, row deletion, or sequence alteration breaks the chain calculation at verification time.
