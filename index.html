Technical Details (Cryptographic Hash Chain Integrity)
Every audit event in the database is linked to the previous event using a cryptographic SHA-256 hash: row_hash = sha256(prev_hash + user_id + action + purpose + timestamp). This makes the log mathematically impossible to alter or re-order without breaking the verification chain.
